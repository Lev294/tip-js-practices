## Модель и файлы
Задача содержит id, title, completed и priority. Id — положительное безопасное целое число. Название — строка от 1 до 100 символов после trim(). Статус — boolean. Приоритет — low, medium или high.

- [data.js](src/data.js) — общий набор и шесть задач варианта 7.
- [task-service.js](src/task-service.js) — девять функций: создание, поиск, выборка, названия, сводка, добавление, статус, переименование и удаление.
- [main.js](src/main.js) — последовательность действий и вывод.
- [checks.js](checks.js) — неизменённые проверки преподавателя.
- [checks.own.js](checks.own.js) — три собственных случая.

Поиск возвращает задачу или undefined; выборки — новые массивы; сводка — объект с числами. Создание возвращает { ok: true, task }, изменения — { ok: true, tasks }, ожидаемая ошибка — { ok: false, error }.

Id не равен индексу: у второй записи общего набора id = 4. Процент остаётся числом без округления; toFixed(1) используется только при выводе. Изменение возвращает новый массив и новый объект выбранной задачи. Остальные объекты можно использовать повторно; исходные записи не меняются.
