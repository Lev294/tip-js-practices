## Запуск

Из корня репозитория перехожу в папку ПР3, запускаю проверки сервиса и сервер:

~~~sh
cd practice-03
npm run check:service
npm start
~~~

Зависимости устанавливать не нужно. Сервер останавливаю через `Ctrl+C`.

После запуска открываю нужную страницу:

- [Общий набор](http://127.0.0.1:5503/)
- [Вариант 7](http://127.0.0.1:5503/index.html?dataset=variant)
- [Эксперименты](http://127.0.0.1:5503/examples/dom-events.html)

Открываю страницы через сервер, потому что в проекте используются ES-модули. Если порт 5503 занят, запускаю `npm start -- 5505` и меняю порт в адресе на 5505.

## Файлы и состояние

Скопировал из ПР2 `data.js` и `task-service.js` и повторно запустил проверки сервиса. Все 35 проверок прошли. Для запуска ПР3 достаточно её папки: нужные файлы лежат внутри.

- [task-selectors.js](src/task-selectors.js) — выборка по фильтру.
- [task-view.js](src/task-view.js) — карточки, сводка и сообщения для пустого списка.
- [main.js](src/main.js) — полный массив `currentTasks`, выбранный фильтр `currentFilter` и обработчики событий.

Для кликов по списку использую один обработчик. Он находит кнопку через `closest()`, преобразует id в число и вызывает функцию из `task-service.js`. Затем `renderApp()` обновляет страницу. Обработчики назначаю один раз, а названия задач вывожу через `textContent`.

## Отладка

Для проверки обработчика выбираю общий набор задач. В DevTools открываю Sources и ставлю две точки в `src/main.js`: на строке 46, где читается id карточки, и на строке 64, где сохраняется результат сервиса. Нажимаю на подпись кнопки «Выполнена» у задачи 4.

На второй точке проверяю значения:

| Переменная | Ожидаемое значение |
| --- | --- |
| rawId | "4", строка из data-task-id |
| id | 4, число после Number() |
| action | "toggle" |
| task.id | 4 |
| result.ok | true |
| result.tasks | Новый массив из четырёх задач; у задачи 4 completed = true |

После продолжения выполнения задача 4 должна получить статус «Выполнена», а общий прогресс — измениться с 50.0% на 75.0%.

На странице экспериментов ставлю точку на строке 25 в `examples/dom-events.js` и нажимаю на текст внутри кнопки. Здесь ожидаю `event.target = span#lab-label` и `event.currentTarget = button#lab-button`: нажимаю на вложенный `span`, а обработчик срабатывает у кнопки. После проверки убираю точки остановки.
